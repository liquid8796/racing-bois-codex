# Licensed scan inputs

These locally downloaded geometry and PBR files come from Poly Haven under CC0. They are source dependencies for an isolated, unaccepted Racing Bois Canyon candidate, not artwork extracted from the reference game. The composition, road, rail, foliage and local modifications follow the inspected original canyon-v2 concept.

- https://polyhaven.com/a/namaqualand_cliff_01 — photography Jenelle van Heerden; modeling Rico Cilliers.
- https://polyhaven.com/a/namaqualand_cliff_02 — photography Dario Barresi; modeling Rico Cilliers.
- https://polyhaven.com/a/namaqualand_boulder_02 — photography Greg Zaal; modeling Rico Cilliers.
- Asset license: https://polyhaven.com/license

`PROVENANCE.json` records all 15 original URLs, source MD5, local SHA256 and byte sizes. Local generation did not use paid services. These scans were transformed, reshaped, tinted and decimated; they are not claimed as wholly self-authored scan geometry. Keep attribution/provenance with this repository even though CC0 does not mandate attribution.

The initial preview CDN requests returned 403 and were not used to obtain the assets. Public asset metadata and direct downloadable source files were accessed normally, then actual local geometry was imported and rendered for inspection through direct Blender MCP.
